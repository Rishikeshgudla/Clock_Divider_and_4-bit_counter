# Clock Divider and 4-Bit Counter in VHDL

This project implements a **Clock Divider** and a **4-Bit Binary Counter** using VHDL. The design demonstrates how a high-frequency input clock can be divided to generate a slower clock signal, which is then used to drive a synchronous counter. The project is intended for FPGA design, digital system learning, and Vivado simulation practice.

---

## Project Overview

The design consists of two modules:

### 1. Clock Divider
The Clock Divider reduces the frequency of the input clock by counting clock cycles and toggling the output clock after a predefined count value.

**Features:**
- Asynchronous active-high reset
- Frequency division using a counter
- Generates a stable low-frequency output clock (`clk_out`)
- Suitable for FPGA-based timing applications

### 2. 4-Bit Counter
The Counter module increments on every rising edge of the divided clock signal generated by the Clock Divider.

**Features:**
- 4-bit synchronous up-counter
- Asynchronous active-high reset
- Counts from 0 to 15 and repeats
- Output available as a 4-bit vector

## Working Principle

### Clock Divider Operation
1. Wait for the rising edge of the input clock.
2. Increment an internal counter.
3. When the counter reaches the terminal count (`49,999,999`), reset the counter.
4. Toggle the divided clock signal (`clk_div`).
5. Continue the process indefinitely.

### Counter Operation
1. Wait for the rising edge of the divided clock.
2. Increment the 4-bit counter value.
3. When the count exceeds `1111` (15), roll over to `0000`.
4. Repeat the counting sequence.

## Simulation

The design can be simulated in **Xilinx Vivado** using the provided testbench.

### Signals Observed
- `clk`
- `reset`
- `clk_out`
- `count[3:0]`

### Expected Results
- The Clock Divider generates a slower clock from the input clock.
- The Counter increments on every rising edge of the divided clock.
- Reset initializes both modules to their default states.
